# HPM284 Audit Checker

Aplikasi daily audit checklist untuk tim Hypermart 284 Ambon City Center.

## Fitur
- Login dengan nama + PIN
- Checklist audit lengkap (Food Safety, Retail Operation, Security, Cash Management, Others)
- Offline support — data tersimpan lokal, sync saat online
- Dashboard progress harian per kategori
- Log aktivitas (siapa masuk, siapa kirim laporan)
- Konfirmasi pengiriman ke database Firebase

## Tech Stack
- Frontend: HTML + CSS + Vanilla JS
- Database: Firebase Firestore
- Hosting: Vercel
